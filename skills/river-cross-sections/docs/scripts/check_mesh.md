# check_mesh.py

Read-only check of a `.2dm` mesh generated by the user with BASEmesh from the derived layers. It is run after the user regenerates the mesh, and before saying the mesh is up to date.

## Requirements

* Interpreter: geo (numpy, geopandas). Without geopandas the materials and nodestrings are not checked.
* A full mesh of about one million elements takes about one minute.

## Inputs

* Argument: the `.2dm` file, relative to the working folder (for example `mesh/quality-mesh.2dm`).
* `outputs`: the derived breaklines, boundary and regions layers, for their dates, the `mat_id` of the region points and the nodestring names.
* `fields.regions.mat_id`, `fields.regions.hole`, `fields.boundary.name`.
* `rules.min_angle_deg`.
* `params.check_mesh.min_edge`: edges shorter than this are a problem (default 0.01 m).
* `params.check_mesh.list`: how many of the worst items to print (default 10).

## Output

Printed only, as a numbered list:

1. Number of nodes, triangles, quadrilaterals and nodestrings.
2. **Date:** the mesh must be newer than the last change of the derived breaklines, boundary and regions.
3. **Shortest edges:** none may be shorter than `min_edge`. A tiny edge reveals a line vertex very close to a crossing.
4. **Smallest element angles,** information only: the count of elements with an angle under `min_angle_deg` and the worst ones.
5. **Materials:** the materials of the elements must equal the `mat_id` of the region points, holes excluded.
6. **Elements with material 0:** they lie in a face without a region point. The line gives their number, centre and extent.
7. **Nodestrings:** the mesh must have the same nodestrings as the layer. When the `.2dm` stores the names they are compared by name, otherwise only counted.

## Usage

```bash
cd <working folder>
<geo python> <skill>/scripts/check_mesh.py mesh/<file>.2dm
```

## How it works

The script reads the `ND`, `E3T`, `E4Q` and `NS` records. A nodestring may span several `NS` lines; a negative node id closes it, and an optional name follows. Edges are collected once each. Angles are computed at every corner of every element.

## Limits

* Only the `.2dm` text format is read.
* Element quality is reported, not judged: BASEmesh controls it through its own angle and area constraints.

Origin: written for the skill on 2026-11-20. On the Brenta mesh of 20 November it found:
* 38 elements with material 0, at the face without a region point;
* a mesh older than the last edit of the layers;
* a shortest edge of 0.55 m. The 0.2 mm edges of the earlier mesh are gone.
